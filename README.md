# Browser-readable firmware

Generated by `release-firmware.yml`; do not edit or merge.

These are the same images attached to release `v0.4.0`,
republished here because GitHub serves release downloads
without the CORS header a web page needs to read them. The
espOS firmware registry's hosted flasher fetches them from
raw.githubusercontent.com, which does send it.

Force-pushed on every release. Holds the current release plus
the two before it; older directories are pruned. The releases
themselves remain the archive, so firmware pruned from here
is still downloadable from its release.
